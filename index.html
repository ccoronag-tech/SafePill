01 / CONOCE EL PROYECTO

¿Qué es SafePill?

SafePill nace como una propuesta para hacer más sencilla la organización de las rutinas de medicamentos, especialmente para personas que administran varios medicamentos o reciben apoyo de familiares.

La idea combina un organizador físico conceptual con una plataforma web que explica el proyecto y ayuda a resolver preguntas frecuentes.
